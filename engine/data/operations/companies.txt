# The known-company list. name,domain,segment
#
# Typed once, on purpose. This is NOT the discovery mechanism — thousands of
# startups come from Common Crawl enumeration and the YC directory, with no names
# typed. The old plan's warning was about typing company names to *discover*
# companies, which is a different thing. This set is small, known, stable, and it
# is the set a B.Tech CSE student actually asks about by name.
#
# The resolver runs over this list and sorts each company into:
#   mechanism 1 (board API)   free, every 12h
#   mechanism 2 (page reader) costs a model call, only when the page hash changes
#
# That split is the AI budget, so it is measured rather than estimated.
# See data/operations/registry.json for the current answer and resolve_companies.py to redo it.
#
# segment values: it_services | big_tech | india_product | quant
